# Ponytail on Stimulants Help

One-shot reference; do not change mode or state.

## Modes

| Mode | Command | Behavior |
|------|---------|----------|
| **focused** | `/ponytail-on-stimulants focused` | Smallest sound design, complete requested path, normal proportional verification. |
| **full-send** | `/ponytail-on-stimulants full-send` | Broader affected-path tracing, implied work, verification, explicit adversarial pass. Default. |
| **feral** | `/ponytail-on-stimulants feral` | Stronger caller/edge search and broader reasonable verification; scope remains bounded. |
| **off** | `/ponytail-on-stimulants off` | Disable the fork's injected behavior. |

`lite`, `full`, and `ultra` are accepted aliases for `focused`, `full-send`, and `feral`. Set the default with `/ponytail-on-stimulants default <mode>` or `PONYTAIL_ON_STIMULANTS_DEFAULT_MODE`.

## Skills

- `/ponytail-on-stimulants-review` — review the current diff for complexity and unfinished work.
- `/ponytail-on-stimulants-audit` — audit the repository with the same bounded-scope lens.
- `/ponytail-on-stimulants-debt` — collect deliberate `ponytail-on-stimulants:` shortcuts.
- `/ponytail-on-stimulants-gain` — explain the upstream benchmark heritage and fork completion metrics.
- `/ponytail-on-stimulants-help` — this card.

## Completion gate

Pi performs a bounded deterministic completion pass after qualifying coding turns: zero forced passes in focused, one in full-send, two in feral. Optional Jev judgment is disabled by default and never replaces deterministic checks.

Stop the fork with `stop ponytail on stimulants` or `stop stimulants`.
